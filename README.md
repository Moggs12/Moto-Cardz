# Moto Cardz V1
Mobile-first web prototype for the motorcycle stat battle game.

## Rules in V1
- Player vs AI
- Player chooses one stat
- Higher score wins the round
- Ties are draws
- Score tracked across rounds
- Core stat categories: Top Speed, Power, Engine, Economy, Value

## Architecture
The UI/game engine is deliberately separated from the bike dataset so the prototype can scale to the full 178-bike dataset, accounts, online multiplayer and native wrappers later.

## Run
Open `index.html` in a modern browser, or deploy the folder to Netlify/Vercel/GitHub Pages.
